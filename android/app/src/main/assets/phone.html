        OpenCode（试用）
        

          
连接电脑上已有的 OpenCode V1 服务。桌面端和 CLI 需连接同一服务；手机通过 SSH 隧道访问，无需开放公网端口。V2 暂未适配。

          
          
          
          
填写 OpenCode 服务的连接密码，和模型 API Key、SSH 密码分别配置。权限和问题确认暂时需要回到 OpenCode 处理。
