开始使用

接上电脑，
再接上管家。

手机直接通过 SSH 连接电脑。
电脑无需安装 agentBridge 服务。

01连接电脑与导入会话
  1. 打开 App，用「发现机器」扫描局域网，或手动填写 SSH 地址、账号和密码／私钥。
  2. 点击「找任务」，导入机器上已有的 Codex、Claude 会话。
  3. 打开员工卡片查看输出、回复指令，或处理待确认事项。

任务状态由手动刷新获取；远程电脑上的会话需要已存在。

02文字聊天与语音通话
  1. 在「管家 → 配置模型」填写服务商地址、模型名和 API Key，保存后点击「验证连接」。
  2. 先发一句文字，确认模型能回复。
  3. 在「语音设置」试听声音，再用聊天框旁的麦克风测试识别。
  4. 两项正常后，点击「拨给管家」，允许麦克风权限。

本机识别或中文播报不可用时，在「语音设置 → 云端语音配置」填写百炼北京地域 API Key。语音密钥和聊天模型可以分开设置。未配置云端语音时，需要手机上可用的识别与播报引擎。

页面截图使用样例记录，连接和通话状态以手机上的实际结果为准。

03安装、更新与版本说明

支持 Android 7.0 及以上。首次安装 APK 时，按系统提示允许浏览器安装应用。正式版可覆盖同一签名的旧正式版；调试版包名不同，会作为另一款应用保留。

下载来自 GitHub Releases，APK 由仓库 CI 从版本标签构建，使用固定发布密钥签名。下载未开始时，可以到全部版本里选择 agentbridge.apk。

0.5.39：调整办公室和管家页布局；新增模型连接验证、消息失败重试与独立语音配置；修复识别卡住、录音切换、挂断后的旧结果误发，以及 Android 7 兼容、凭据加密和远程回复完成状态问题。

04数据保存与隐私

配置、对话与记录保存在手机应用私有存储。密码与 API Key 使用 Android Keystore 加密，应用没有统计上报。

聊天会把必要的任务信息发送到你配置的模型服务。使用百炼云端语音时，录音或播报文字会发送到百炼。详见安全说明。
