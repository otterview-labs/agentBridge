装好以后

01 / 连接电脑

  1. 使用「发现机器」或手动添加 SSH 地址、账号与凭据。
  2. 点击「找任务」，导入机器上的 Codex、Claude 会话。
  3. 通过卡片查看输出、回复指令，或处理待确认事项。

手机直接通过 SSH 连接。电脑无需安装 agentBridge 服务，任务状态由手动刷新获取。

02 / 聊天与通话

  1. 在「管家 → 配置模型」填写服务商地址、模型名与 API Key，保存后点击「验证连接」。
  2. 发送文字验证模型回复。失败将保留原文供重试。
  3. 在「语音设置」试听声音，再用聊天框旁的麦克风测试识别。
  4. 两项正常后，点击「拨给管家」，允许麦克风权限。
本机识别或中文播报不可用时，在「语音设置 → 云端语音配置」填写百炼北京地域 API Key。语音密钥与聊天模型可以分开设置；未配置云端语音时，需要手机上可用的识别与播报引擎。

0.5.39 更新日志

新版保留像素办公室，调整管家页布局。新增模型连接验证、失败消息保留和重试、独立语音密钥配置。修复识别无结果卡住、录音切换、挂断后旧结果误发，以及 Android 7 兼容、凭据加密与远程回复完成状态问题。

数据安全与隐私

配置、对话与记录保存在手机应用私有存储；密码和 API Key 使用 Android Keystore 加密。聊天会把必要的任务信息发送到你配置的模型服务；使用百炼云端语音时，录音或播报文字会发送到百炼。应用没有统计上报。
