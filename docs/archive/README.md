# Archived design notes

These documents describe the self-hosted Hub (HTTP API, Feishu, tmux runner,
web Studio) that agentBridge started as. That backend is no longer part of this
repository, so none of the commands, endpoints or environment variables here
apply to the Android app. They are kept for the design history only.

For the app that ships from this repository, see
[`docs/android-app.md`](../android-app.md).
